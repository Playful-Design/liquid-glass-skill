---
name: prism
description: Shortcut that applies the prism glass (real optical prism glass: clear colorless body, physical dispersion, color where split light lands) to an existing glass GLSL shader, from any glass skill or the user's own. Physics only, never adds elements. Use when the user runs /prism or asks to turn an existing shader into a prism.
---

Apply `materials/prism.md` from the `shader-liquid-glass` skill (installed next to this one: `../shader-liquid-glass/materials/prism.md`) to the user's shader, following that skill's section 1b. Save `<name>.prism.glsl` next to the original and leave the original unchanged.
