---
name: shard
description: Shortcut that applies the shard glass (real broken window glass: low head-on reflection, faint green tint at the edges, no rainbow) to an existing glass GLSL shader, from any glass skill or the user's own. Physics only, never adds elements. Use when the user runs /shard or asks to turn an existing shader into broken glass or a shard.
---

Apply `materials/shard.md` from the `liquid-glass-skill` skill (installed next to this one: `../liquid-glass-skill/materials/shard.md`) to the user's shader, following that skill's section 1b. Save `<name>.shard.glsl` next to the original and leave the original unchanged.
