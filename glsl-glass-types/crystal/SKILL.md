---
name: crystal
description: Shortcut that applies the crystal glass (real cut crystal: bright internal reflections, color only as small flecks) to an existing glass GLSL shader, from any glass skill or the user's own. Physics only, never adds elements. Use when the user runs /crystal or asks to turn an existing shader into crystal, a gem or cut glass.
---

Apply `materials/crystal.md` from the `liquid-glass-skill` skill (installed next to this one: `../liquid-glass-skill/materials/crystal.md`) to the user's shader, following that skill's section 1b. Save `<name>.crystal.glsl` next to the original and leave the original unchanged.
